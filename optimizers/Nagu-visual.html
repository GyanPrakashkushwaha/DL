Nesterov Accelerated Gradient

Understanding the "Lookahead" Step

Both Standard Momentum and NAG use past gradients to build velocity. The key difference is where they calculate the current gradient.

1. Standard Momentum

Calculates gradient at current position, then adds momentum.

$$v_{t} = \gamma v_{t-1} + \eta \nabla J(\theta_{t})$$ $$\theta_{t+1} = \theta_{t} - v_{t}$$

2. Nesterov (NAG)

Takes a "lookahead" step using momentum first, calculates gradient there, then makes the final update.

$$ \text{Lookahead: } \tilde{\theta} = \theta_{t} - \gamma v_{t-1} $$ $$v_{t} = \gamma v_{t-1} + \eta \nabla J(\tilde{\theta})$$ $$\theta_{t+1} = \theta_{t} - v_{t}$$
